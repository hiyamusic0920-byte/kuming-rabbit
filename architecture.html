Setting guide

漫畫裡的每一個設定，在真實系統裡都有對應的東西

苦命兔的故事不是憑空想像的。這頁把漫畫設定跟真實系統一條一條對起來，方便看完漫畫的人接到技術內容。

對照表

誰是誰，什麼是什麼。

  • 苦命兔 · Claude Code

    預設的執行者。跑主線流程、寫測試腳本、出報告。故事裡那些「很有自信地說沒問題」的場面都是真的。

  • 苦力怕 · Codex

    對等的第二個 agent，不是下屬。個性偏減法，常常拆掉前一個 agent 想加的東西——這也是牠存在的價值。

    出場：第 04 話 · 第 11 話

  • 家規 · 共用規則檔

    兩個 agent 讀同一份規則檔，所以規則只要維護一次。裡面寫的多半是「不准做什麼」，不是「怎麼做才對」。

    相關：第 07 話 · 第 14 話 · 治理層 →

  • 秘密小本本 · 知識層

    商業規則、UI 陷阱、測試資料怎麼造、跨 agent 討論的結論，全部落成 repo 裡的檔案。Agent 可以換，repo 才是真理來源。

    相關：第 03 話 · 第 12 話 · 知識層 →

  • 十一道關卡 · QA Workflow

    從一張票到報告的 11 步主線。其中三步 AI 不能自己過，要我簽。

    相關：第 05 話 · 看 11 步 →

  • 交作業 · QA / UAT PDF

    最終交付物。統一的 renderer 讀證據 JSON 產出報告，要能過稽核——這件事決定了整套流程的形狀。

    相關：第 01 話 · 第 02 話

Agent 可換，repo 才是真理來源。聊天記錄和模型的記憶都不是。
